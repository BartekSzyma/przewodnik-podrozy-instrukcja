# Przewodnik podróży z Claude Code

Instrukcja krok po kroku: jak z Claude Code zbudować przewodnik po podróży, w którym każda informacja ma źródło i datę (część A: wyszukiwanie i plan), oraz stronę HTML z mapą, zdjęciami i przelicznikiem walut (część B).

- Strona: https://bartekszyma.github.io/przewodnik-podrozy-instrukcja/
- Wynik wzorcowy (przewodnik po Argentynie, marzec 2027): folder `wynik-wzorcowy/`

Zdjęcia w wyniku wzorcowym pochodzą z Wikimedia Commons; autorzy i licencje są w stopkach strony. Ceny, loty i godziny w wyniku wzorcowym pochodzą z października 2026 roku i służą jako przykład, a nie aktualna oferta.
